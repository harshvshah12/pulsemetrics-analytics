# PulseMetrics Cloud Analytics

> High-throughput real-time telemetry and edge analytics

Built autonomously from voice requirements using **[VoxBuild AI](https://voxbuild.ai)**.

## Architecture
- **Framework**: Next.js 15 (App Router) & React 19
- **Archetype**: SAAS
- **Styling**: Tailwind CSS (Dark Obsidian Luxe with Neon Cyan Accents)
- **Backend**: Ready for Supabase PostgreSQL
- **Deployed on**: Vercel Global Edge Network

## Getting Started
```bash
npm install
npm run dev
```
